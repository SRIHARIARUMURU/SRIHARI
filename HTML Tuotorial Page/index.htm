HTML Tutorial

Hyper Text Markup Language

What is HTML?

HTML (HyperText Markup Language) is the standard language used to create webpages. It tells the browser how to display content like text, images, links, videos, and more.

HTML = Structure of a Webpage

Just like a skeleton gives structure to a body, HTML gives structure to a webpage.

1.Document Structure Tags

Document Structure Tags are HTML tags that define the structure and organization of a web page. They help browsers and assistive technologies understand the layout and meaning of the content. Here are the most common document structure tags in HTML:

Tag Description
<!DOCTYPE> Declares the document type (HTML5)
<html> Root of the HTML document
<head> Metadata container
<title> Title in browser tab
<meta> Metadata like charset, viewport
<link> Links external files (e.g., CSS)
<style> Internal CSS
<script> JavaScript embedding
<base> Base URL for links

2. Sectioning Tags (Semantic)

Semantic sectioning tags are HTML5 elements that clearly define different parts or sections of a web page. They give meaning to the content, making it easier for browsers, developers, and assistive technologies (like screen readers) to understand and navigate the structure of a page.

Tag Description
<header> Top of a section/page
<nav> Navigation menu
<main> Main content
<section> A distinct content area
<article> Self-contained content
<aside> Sidebar/related content
<footer> Bottom section
<h1> to <h6> Headings
<address> Contact info

3. Text Content Tags

Text content tags in HTML are used to display, organize, and emphasize textual information on a web page. These tags help browsers understand how to present text and also convey meaning and importance to users and assistive technologies.

Tag Description Tag Description
<p> Paragraph <time> Time or date
<br> Line break <b> Bold (no emphasis)
<hr> Horizontal line <strong> Strong importance
<pre> Preformatted text <i> Italics (no emphasis)
<blockquote> Quoted block <em> Emphasis
<code> Inline code <small> Smaller text
<kbd> Keyboard input <del> Deleted text
<samp> Sample output <ins> Inserted text
<var> Variable <sub> Subscript
<abbr> Abbreviation <sup> Superscript
<cite> Citation <spam> Generic inline container
<mark> Highlighted text <dfn> Definition term

Conclusion
